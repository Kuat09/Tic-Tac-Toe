#Tic-Tac-Toe Arena
Консольная игра в классические крестики-нолики на поле 3×3 для двух игроков.

Как запустить
Для запуска используйте:

go run .

Доступные флаги:

go run . --help
go run . --name
go run . --color
go run . --verbose
go run . --first

Флаги
--help — показывает справку по доступным параметрам и завершает программу.
--name — позволяет ввести имена двух игроков.
--color — включает цветной вывод.
--verbose — включает подробную статистику.
--first — позволяет выбрать, какой игрок будет ходить первым.
Правила
Игра проходит на поле 3×3:

 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9

Игроки по очереди выбирают свободную клетку, вводя её номер от 1 до 9.

Первым по умолчанию ходит игрок 1.

Игрок побеждает, если занимает три клетки подряд:

по горизонтали;
по вертикали;
по диагонали.
Если все клетки заняты и победитель не определён, игра заканчивается ничьей.

После окончания партии программа предлагает сыграть ещё раз:

Хочешь сыграть еще раз? (y/n)

При выборе y начинается новая партия.

При выборе n программа выводит статистику и завершает работу.

Имена игроков
Для ввода имён используется:

go run . --name

Каждое имя не может быть пустым и должно содержать не более одного символа. Имена игроков не могут быть одинаковыми.

Выбор первого игрока
Для выбора первого игрока используется:

go run . --first

Программа предлагает:

Выберите, кто будет ходить первым:
1. Игрок 1
2. Игрок 2

По умолчанию первым ходит игрок 1.

Цветной вывод
Для включения цветного вывода используется:

go run . --color

В цветном режиме символ первого игрока отображается красным, а второго — синим. Сообщения об ошибках и победе также используют цвета.

Подробная статистика
Флаг:

go run . --verbose

включает дополнительный вывод статистики.

После окончания игры выводится количество сделанных ходов и процент побед каждого игрока.

Пример игры
Запуск:

go run .

Пример последовательности ходов:

1
2
4
5
7

Результат:

Победил X
Хочешь сыграть еще раз? (y/n)

Игрок X победил, заняв клетки 1, 4 и 7.

Если все девять клеток заняты без победителя, выводится:

Ничья

Статистика
После завершения игры выводится:

Статистика:
Всего игр: 1
Победы X: 1
Победы O: 0
Ничьи: 0

Статистика включает:

общее количество сыгранных игр;
победы первого игрока;
победы второго игрока;
количество ничьих.
